# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 3.2.x   | :white_check_mark: |
| < 3.2   | :x:                |

## Reporting a Vulnerability

Security of user email data, integrity verification, and cryptographic chain-of-custody are top priorities for `mail2rust`.

If you discover a security vulnerability or data loss bug:
1. **Do not disclose it publicly** via GitHub Issues.
2. Submit a report privately via GitHub Private Vulnerability Reporting under the Security tab:
   `https://github.com/adpaolucci/mail2rust/security/advisories/new`
3. You will receive an acknowledgment within 48 hours.
4. A security patch and advisory will be coordinated and released promptly.
